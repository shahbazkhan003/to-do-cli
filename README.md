TO-DO LIST CLI APP (Python)

Features

- Add Task – Add new tasks to your to-do list
- View Task – View all tasks with numbering
- Update Task – Update the name of an existing task
- Delete Task – Delete any task from the list
- Exit – Exit the application

 How to Run This Project

Prerequisites
    make sure install (python3)

Steps to Run:
    - open the terminal
    - run the cammand (python todo.py)
